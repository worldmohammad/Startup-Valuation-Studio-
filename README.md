## ✨ Features

- **🧮 Scorecard Method (Bill Payne):** 6 factors with customizable weights
- **📈 Berkus Method:** Progress-based valuation with configurable caps (Pro)
- **⚠️ Risk Factor Summation:** 8 risk factors with adjustable impact (Pro)
- **📊 Interactive Charts:** Radar profile + Value contribution bar chart
- **⚖️ Side-by-Side Comparison:** Compare two startups visually
- **📁 Valuation Archive:** Save and reload past valuations (Pro)
- **🖨️ Professional Reports:** Print-ready A4 reports (Pro)
- **💾 Data Export/Import:** JSON backup and restore (Pro)
- **🔒 100% Offline:** All data in localStorage—never leaves your browser
